# USER_FLOWS - Recorridos principales

## 1. Alta de empresa y primer acceso
1. El usuario crea una cuenta.
2. Registra una organización.
3. Crea una sucursal inicial.
4. Invita o crea usuarios con roles.
5. Accede al panel principal.

## 2. Crear productos y stock inicial
1. El administrador ingresa a Productos.
2. Crea categorías y productos.
3. Ajusta inventario inicial.
4. Confirma movimientos de stock auditables.

## 3. Apertura de caja y venta
1. El cajero abre una caja con monto inicial.
2. Accede al POS.
3. Busca productos y arma el carrito.
4. Selecciona cliente y medios de pago.
5. Confirma la venta.
6. El sistema descuenta stock y registra movimientos de caja.

## 4. Gestión gastronómica
1. El mozo abre una mesa.
2. Carga pedidos y los envía a cocina.
3. Cocina actualiza el estado.
4. Se cobra la cuenta y se cierra la mesa.

## 5. Cierre de caja y reportes
1. El responsable cierra la caja.
2. Se comparan ventas esperadas y declaradas.
3. Se generan reportes y auditoría.
